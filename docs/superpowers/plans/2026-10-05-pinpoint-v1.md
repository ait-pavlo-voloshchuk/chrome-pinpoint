# Pinpoint v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Manifest V3 Chrome extension that lets the user pin any element on any page, comment on it, and copy a precise Markdown/JSON reference (selector, DOM path, styles, cropped screenshot, React component chain + source when available) for pasting into Claude Code.

**Architecture:** Three bundles built by esbuild: a service worker (`background.js`: activation, screenshots, downloads, badge), an isolated-world content script (`content.js`: pin mode, capture, overlay UI in a Shadow DOM, per-tab persistence), and a main-world probe (`probe.js`: reads React fibers). Capture and serialization are pure modules with Vitest + jsdom unit tests; the full flow is covered by one Playwright e2e test against a React fixture.

**Tech Stack:** TypeScript 5.x, esbuild, Vitest + jsdom, Playwright (Chromium), `@types/chrome`. No UI framework. Node 22 via mise.

**Spec:** `docs/superpowers/specs/2026-10-05-pinpoint-design.md`

## Global Constraints

- **No git commits or pushes.** User's standing rule: leave all work uncommitted unless explicitly asked. Every task ends with a green-tests checkpoint instead of a commit.
- Node 22 via `mise.toml` (`[tools] node = "22"`); run commands through mise (`mise exec -- npm …`) if `node` is not on PATH.
- Manifest V3, `minimum_chrome_version: "120"`.
- Permissions exactly: `activeTab`, `scripting`, `storage`, `downloads`, `downloads.ui`. No `host_permissions` in production builds (the e2e build adds `<all_urls>`).
- Default shortcut `Alt+P`, command name `toggle-pin-mode`.
- Overlay lives in a Shadow DOM under a `<pinpoint-overlay>` host on `document.documentElement`, `z-index: 2147483647`.
- Accent color `#d97757`.
- Schema version `1`; Markdown block starts with `<!-- pinpoint:v1 -->`.
- Screenshots save to `pinpoint/<sessionId>/pin-<n>.png` under the Downloads folder; Markdown references the absolute path.
- Pin numbers are monotonic within a session and never renumbered.
- Element text max 80 chars, attribute values max 120 chars, DOM path last 5 levels, selector climb max depth 8, probe timeout 150 ms, mutation debounce 200 ms, screenshot padding 8 px, capture retry after 600 ms.

### Deviations from the spec (flag to user at handoff)

1. **esbuild instead of Vite + `@crxjs/vite-plugin`.** crxjs emits content scripts as ES-module loaders that call `chrome.runtime.getURL`, which does not exist in the MAIN world and breaks `executeScript({ world: 'MAIN' })`. esbuild IIFE bundles are classic scripts that work in every context.
2. **Probe protocol uses composed `CustomEvent`s** (`pp:probe` dispatched on the element, `pp:probe:result` on `window`, string details) instead of a temporary `data-pp-probe` attribute. Same nonce validation; it also reaches elements inside open shadow roots.
3. **`downloads.ui` permission added** so each screenshot save does not flash Chrome's download bubble.
4. **Schema adds `element.selectorMatches` and `session.nextN`** (needed for the "(matches N)" note and monotonic numbering).
5. **"Clear" starts a fresh session id** so new screenshots never overwrite files referenced by an earlier paste.
6. **Shadow root is `open`** (Playwright can only pierce open roots; nothing in the spec required closed).

## Review Focus

1. **Page wipes the overlay host** (frameworks or scripts that replace `<html>` children) — the overlay must re-attach on the next mutation tick. Test in Task 8 (`ensureAttached`).
2. **Typing in the comment bubble triggers page hotkeys** (Enter/letters reaching `document` listeners) — key events must stop at the bubble/tray. Test in Task 8.
3. **Tray re-renders while the user edits a comment** (page mutations fire constantly) — the textarea being edited must not be replaced. Test in Task 8.
4. **Ids and classes with CSS-special characters** (`user.name`, Tailwind `hover:bg-x`) — selectors must be escaped or skip variant classes and still resolve to the element. Test in Task 3.
5. **A hostile or broken page forges the probe reply** — malformed `react` payloads must be sanitized, never trusted structurally; backticks in element text must not break Markdown code spans. Tests in Task 5 and Task 2.

export const SCHEMA_VERSION = 1 as const;

export type StyleGroup = 'layout' | 'spacing' | 'typography' | 'visual';
export type GroupedStyles = Record<StyleGroup, Record<string, string>>;

export interface Box { x: number; y: number; width: number; height: number; }
export interface Viewport { width: number; height: number; dpr: number; }

export interface ElementInfo {
  selector: string;
  /** How many elements the selector matches; 1 unless the climb hit max depth. */
  selectorMatches: number;
  domPath: string;
  tag: string;
  text: string | null;
  attributes: Record<string, string>;
  box: Box;
  viewport: Viewport;
  styles: GroupedStyles;
}

export interface ReactInfo {
  /** Component names, nearest first. */
  components: string[];
  minified: boolean;
  /** "path:line:col" from data-pp-src, if present. */
  source: string | null;
}

export interface Screenshot { path: string; clipped: boolean; }

export interface Pin {
  n: number;
  comment: string;
  createdAt: string;
  status: 'attached' | 'detached';
  element: ElementInfo;
  react: ReactInfo | null;
  screenshot: Screenshot | null;
}

export interface PinSession {
  version: typeof SCHEMA_VERSION;
  id: string;
  page: { url: string; title: string };
  pins: Pin[];
  /** Number the next pin will get. Never decreases except when discarding the newest pin. */
  nextN: number;
}

/** "2026-10-05T10-42-13" — safe as a folder name. */
export function sessionId(date: Date): string {
  return date.toISOString().slice(0, 19).replace(/:/g, '-');
}

```ts
import { SCHEMA_VERSION, sessionId, type Pin, type PinSession } from '../shared/schema';

export interface StoreState {
  current: PinSession | null;
  previous: PinSession | null;
}

export type NewPin = Omit<Pin, 'n'>;

export function newSession(url: string, title: string, now: Date): PinSession {
  return { version: SCHEMA_VERSION, id: sessionId(now), page: { url, title }, pins: [], nextN: 1 };
}

/** Same origin + pathname; query and hash changes do not start a new session. */
export function samePage(a: string, b: string): boolean {
  try {
    const ua = new URL(a);
    const ub = new URL(b);
    return ua.origin === ub.origin && ua.pathname === ub.pathname;
  } catch {
    return a === b;
  }
}

export function sessionFor(state: StoreState, url: string, title: string, now: Date): StoreState {
  if (state.current && samePage(state.current.page.url, url)) return state;
  const previous = state.current && state.current.pins.length > 0 ? state.current : state.previous;
  return { current: newSession(url, title, now), previous };
}

export function addPin(s: PinSession, data: NewPin): { session: PinSession; pin: Pin } {
  const pin: Pin = { ...data, n: s.nextN };
  return { session: { ...s, pins: [...s.pins, pin], nextN: s.nextN + 1 }, pin };
}

export function updateComment(s: PinSession, n: number, comment: string): PinSession {
  return { ...s, pins: s.pins.map(p => (p.n === n ? { ...p, comment } : p)) };
}

export function removePin(s: PinSession, n: number): PinSession {
  return { ...s, pins: s.pins.filter(p => p.n !== n) };
}

/** Removes a just-created pin; gives its number back if it was the newest. */
export function discardNewPin(s: PinSession, n: number): PinSession {
  const removed = removePin(s, n);
  return n === s.nextN - 1 ? { ...removed, nextN: n } : removed;
}

export function setStatuses(s: PinSession, statuses: ReadonlyMap<number, Pin['status']>): PinSession {
  let changed = false;
  const pins = s.pins.map(p => {
    const status = statuses.get(p.n);
    if (!status || status === p.status) return p;
    changed = true;
    return { ...p, status };
  });
  return changed ? { ...s, pins } : s;
}

export function clearPins(s: PinSession, now: Date): PinSession {
  return newSession(s.page.url, s.page.title, now);
}

export function swapPrevious(state: StoreState): StoreState {
  if (!state.previous) return state;
  const keep = state.current && state.current.pins.length > 0 ? state.current : null;
  return { current: state.previous, previous: keep };
}
```

export const MARKER = '<!-- pinpoint:v1 -->';

export function toMarkdown(s: PinSession): string {
  const lines: string[] = [MARKER, `## UI pins — ${s.page.title || s.page.url}`];
  const meta = [s.page.url];
  const vp = s.pins[0]?.element.viewport;
  if (vp) meta.push(`${vp.width}×${vp.height} @${fmt(vp.dpr)}x`);
  meta.push(`${s.pins.length} ${s.pins.length === 1 ? 'pin' : 'pins'}`);
  lines.push(meta.join(' · '));
  for (const pin of s.pins) lines.push('', ...pinLines(pin));
  return lines.join('\n') + '\n';
}

export function toJson(s: PinSession): string {
  return JSON.stringify(s, null, 2);
}

export function compactStyles(st: GroupedStyles): string {
  const t = st.typography;
  const v = st.visual;
  const parts: string[] = [];
  const size = t['font-size'] ? t['font-size'] + (t['line-height'] ? `/${t['line-height']}` : '') : '';
  const font = [size, t['font-weight'], t['font-family']].filter(Boolean).join(' ');
  if (font) parts.push(`font ${font}`);
  if (t.color) parts.push(`color ${t.color}`);
  if (v['background-color']) parts.push(`bg ${v['background-color']}`);
  if (st.spacing.padding) parts.push(`padding ${st.spacing.padding}`);
  if (v['border-radius']) parts.push(`radius ${v['border-radius']}`);
  if (v.border) parts.push(`border ${v.border}`);
  if (v['box-shadow']) parts.push(`shadow ${v['box-shadow']}`);
  return parts.join(' · ');
}

function pinLines(p: Pin): string[] {
  const [first, ...rest] = (p.comment.trim() || '(no comment)').split('\n');
  const out = [`### ${p.n}. ${first}`];
  for (const line of rest) out.push(`> ${line}`);

  const e = p.element;
  const text = e.text ? ` "${e.text.replace(/`/g, "'")}"` : '';
  out.push(`- **Element:** \`<${e.tag}>${text}\``);
  out.push(`- **Selector:** \`${e.selector}\`${e.selectorMatches > 1 ? ` (matches ${e.selectorMatches})` : ''}`);
  if (p.status === 'detached') out.push('- **Status:** detached (element no longer found on page)');
  out.push(`- **Path:** \`${e.domPath}\``);
  if (p.react && p.react.components.length > 0) {
    const chain = p.react.components.map(c => `\`${c}\``).join(' ← ');
    out.push(`- **React:** ${chain}${p.react.minified ? ' (minified names)' : ''}`);
  }
  if (p.react?.source) out.push(`- **Source:** \`${p.react.source}\``);
  out.push(`- **Box:** ${e.box.width}×${e.box.height} at (${e.box.x}, ${e.box.y})`);
  const styles = compactStyles(e.styles);
  if (styles) out.push(`- **Styles:** ${styles}`);
  if (p.screenshot) out.push(`- **Screenshot:** ${p.screenshot.path}${p.screenshot.clipped ? ' (clipped to viewport)' : ''}`);
  return out;
}

function fmt(n: number): string {
  return String(Math.round(n * 100) / 100);

const UNSTABLE_ID = /\d{4,}|[a-f0-9]{8,}|^[:«]r|^radix-|^headlessui-/;

const HASHED_CLASS: RegExp[] = [
  /^css-[a-z0-9]+$/i,           // emotion
  /^sc-/,                        // styled-components
  /^_[a-zA-Z0-9]{5,}$/,          // generic hash
  /__[a-zA-Z0-9_-]{5}$/,         // css-modules (webpack)
  /^_[\w-]+_[a-z0-9]{5}_\d+$/,   // css-modules (vite)
  /^jsx-\d+$/,                   // styled-jsx
  /^svelte-[a-z0-9]+$/,
  /[[\]:]/,                      // tailwind variants / arbitrary values
];

export function isStableId(id: string): boolean {
  return id.length > 0 && !UNSTABLE_ID.test(id);
}

export function stableClasses(el: Element): string[] {
  return Array.from(el.classList).filter(c => !HASHED_CLASS.some(r => r.test(c)));
}

/** CSS.escape with a spec-compliant fallback (jsdom lacks it). */
export function cssEscape(value: string): string {
  if (typeof CSS !== 'undefined' && typeof CSS.escape === 'function') return CSS.escape(value);
  let out = '';
  for (let i = 0; i < value.length; i++) {
    const ch = value[i];
    const code = value.charCodeAt(i);
    if (code === 0) { out += '\uFFFD'; continue; }
    const isDigit = code >= 48 && code <= 57;
    if ((code >= 1 && code <= 31) || code === 127 || (i === 0 && isDigit) || (i === 1 && isDigit && value.charCodeAt(0) === 45)) {
      out += `\\${code.toString(16)} `;
      continue;
    }
    if (i === 0 && value.length === 1 && code === 45) { out += `\\${ch}`; continue; }
    if (code >= 128 || code === 45 || code === 95 || isDigit || (code >= 65 && code <= 90) || (code >= 97 && code <= 122)) {
      out += ch;
      continue;
    }
    out += `\\${ch}`;
  }
  return out;
}

import { cssEscape, isStableId, stableClasses } from './stability';

export interface SelectorResult { selector: string; matches: number; }

const TEST_ATTRS = ['data-testid', 'data-test', 'data-cy', 'data-qa'];
const LABEL_ATTRS = ['aria-label', 'name', 'role'];
const MAX_DEPTH = 8;

export function buildSelector(el: Element): SelectorResult {
  const root = el.getRootNode() as Node;
  const local = localSelector(el, root as unknown as ParentNode);
  let prefix = '';
  const host = (root as Partial<ShadowRoot>).host;
  if (root.nodeType === Node.DOCUMENT_FRAGMENT_NODE && host) {
    prefix = `${buildSelector(host).selector} >>> `;
  } else {
    const frame = el.ownerDocument.defaultView?.frameElement;
    if (frame) prefix = `${buildSelector(frame).selector} >>> `;
  }
  return { selector: prefix + local.selector, matches: local.matches };
}

function localSelector(el: Element, scope: ParentNode): SelectorResult {
  const own = firstUnique(el, scope);
  if (own) return { selector: own, matches: 1 };
  const parts = [segment(el)];
  let cur = el.parentElement;
  for (let depth = 1; cur && depth < MAX_DEPTH; depth++) {
    const anchor = firstUnique(cur, scope);
    if (anchor) {
      const selector = [anchor, ...parts].join(' > ');
      return { selector, matches: count(scope, selector) };
    }
    parts.unshift(segment(cur));
    cur = cur.parentElement;
  }
  const selector = parts.join(' > ');
  return { selector, matches: count(scope, selector) };
}

function attr(name: string, value: string): string {
  return `[${name}="${value.replace(/["\\]/g, '\\$&')}"]`;
}

function classSuffix(el: Element, max: number): string {
  return stableClasses(el).slice(0, max).map(c => `.${cssEscape(c)}`).join('');
}

function candidates(el: Element): string[] {
  const tag = cssEscape(el.localName);
  const out: string[] = [];
  if (el.id && isStableId(el.id)) out.push(`#${cssEscape(el.id)}`);
  for (const a of TEST_ATTRS) {
    const v = el.getAttribute(a);
    if (v) out.push(attr(a, v));
  }
  for (const a of LABEL_ATTRS) {
    const v = el.getAttribute(a);
    if (v) out.push(tag + attr(a, v));
  }
  const classes = classSuffix(el, 3);
  if (classes) out.push(tag + classes);
  out.push(tag);
  return out;
}

function count(scope: ParentNode, selector: string): number {
  try {
    return scope.querySelectorAll(selector).length;
  } catch {
    return Number.POSITIVE_INFINITY;
  }
}

function firstUnique(el: Element, scope: ParentNode): string | null {
  return candidates(el).find(c => count(scope, c) === 1) ?? null;
}

/** One path step: tag + up to 2 stable classes + nth-of-type when siblings share the tag. */
function segment(el: Element): string {
  let s = cssEscape(el.localName) + classSuffix(el, 2);
  const siblings = (el.parentNode as ParentNode | null)?.children;
  if (siblings) {
    const same = Array.from(siblings).filter(c => c.localName === el.localName);
    if (same.length > 1) s += `:nth-of-type(${same.indexOf(el) + 1})`;
  }
  return s;
}

/** Resolves a selector produced by buildSelector, following " >>> " shadow/iframe hops. */
export function resolveSelector(selector: string, doc: Document = document): Element | null {
  const parts = selector.split(' >>> ');
  let scope: ParentNode | null = doc;
  let el: Element | null = null;
  for (let i = 0; i < parts.length; i++) {
    if (!scope) return null;
    try {
      el = scope.querySelector(parts[i]);
    } catch {
      return null;
    }
    if (!el) return null;
    if (i < parts.length - 1) scope = el.shadowRoot ?? frameDocument(el);
  }
  return el;
}

function frameDocument(el: Element): Document | null {
  try {
    return (el as HTMLIFrameElement).contentDocument ?? null;
  } catch {
    return null;
  }
}

import { isStableId, stableClasses } from './stability';

export function elementLabel(el: Element): string {
  if (el.id && isStableId(el.id)) return `${el.localName}#${el.id}`;
  const cls = stableClasses(el)[0];
  return cls ? `${el.localName}.${cls}` : el.localName;
}

export function domPath(el: Element, levels = 5): string {
  const parts: string[] = [];
  let cur: Element | null = el;
  while (cur && parts.length < levels) {
    if (cur.localName === 'html' || cur.localName === 'body') break;
    parts.unshift(elementLabel(cur));
    cur = cur.parentElement ?? (cur.getRootNode() as Partial<ShadowRoot>).host ?? null;
  }
  return parts.join(' > ');
}

function border(get: (p: string) => string): string {
  const sides = SIDES.map(s => ({ s, w: get(`border-${s}-width`), style: get(`border-${s}-style`), c: get(`border-${s}-color`) }));
  const visible = sides.filter(x => x.style && x.style !== 'none' && x.style !== 'hidden' && x.w !== '0px');

  const fmt = (x: (typeof sides)[number]) => [x.w, x.style, x.c].filter(Boolean).join(' ');
  if (visible.length === 4 && new Set(visible.map(fmt)).size === 1) return fmt(visible[0]);

function rgbToHex(inner: string): string | null {

/** Element rect in the top window's viewport, adding same-origin iframe offsets. */
export function rectInTopViewport(el: Element): Box {
  const r = el.getBoundingClientRect();
  let x = r.left;
  let y = r.top;
  let win: Window | null = el.ownerDocument.defaultView;
  while (win && win !== window) {
    const frame = win.frameElement;
    if (!frame) break;
    const fr = frame.getBoundingClientRect();
    x += fr.left + frame.clientLeft;
    y += fr.top + frame.clientTop;
    win = frame.ownerDocument.defaultView;
  }
  return { x, y, width: r.width, height: r.height };
}

import type { ReactInfo } from '../shared/schema';
import { PROBE_EVENT, PROBE_RESULT_EVENT } from '../shared/messages';

interface Fiber { type: unknown; return: Fiber | null; }

const WRAPPER = /^(Fragment|Suspense|StrictMode|Profiler|ForwardRef|Memo)$|(Provider|Context|Consumer)$/;
const MAX_COMPONENTS = 5;
const MAX_ANCESTOR_HOPS = 10;
const NONCE = /^[a-z0-9]{8,32}$/;

function fiberOf(el: Element): Fiber | null {
  for (const key of Object.keys(el)) {
    if (key.startsWith('__reactFiber$') || key.startsWith('__reactInternalInstance$')) {
      return (el as unknown as Record<string, Fiber>)[key];
    }
  }
  return null;
}

function nameOf(type: unknown): string | null {
  if (!type || typeof type === 'string') return null;
  if (typeof type === 'function') {
    const f = type as { displayName?: string; name?: string };
    return f.displayName || f.name || null;
  }
  if (typeof type === 'object') {
    const o = type as { displayName?: string; type?: unknown; render?: unknown };
    return o.displayName || nameOf(o.type) || nameOf(o.render) || null;
  }
  return null;
}

export function reactInfoFor(el: Element): ReactInfo | null {
  let fiber: Fiber | null = null;
  let host: Element | null = el;
  for (let i = 0; host && !fiber && i < MAX_ANCESTOR_HOPS; i++) {
    fiber = fiberOf(host);
    host = host.parentElement;
  }
  const components: string[] = [];
  for (let f = fiber; f && components.length < MAX_COMPONENTS; f = f.return) {
    const name = nameOf(f.type);
    if (!name || WRAPPER.test(name) || components[components.length - 1] === name) continue;
    components.push(name);
  }
  const source = el.closest('[data-pp-src]')?.getAttribute('data-pp-src') ?? null;
  if (!fiber && !source) return null;
  return { components, minified: components.some(n => n.length <= 2), source };
}

export function installProbe(win: Window): void {
  const w = win as Window & { __ppProbe?: boolean };
  if (w.__ppProbe) return;
  w.__ppProbe = true;
  win.addEventListener(PROBE_EVENT, e => {
    const nonce = (e as CustomEvent).detail;
    if (typeof nonce !== 'string' || !NONCE.test(nonce)) return;
    const target = e.composedPath()[0] as Node | undefined;
    const react = target && target.nodeType === Node.ELEMENT_NODE ? reactInfoFor(target as Element) : null;
    win.dispatchEvent(new CustomEvent(PROBE_RESULT_EVENT, { detail: JSON.stringify({ nonce, react }) }));
  }, true);
}

import type { ReactInfo } from '../shared/schema';
import { PROBE_EVENT, PROBE_RESULT_EVENT } from '../shared/messages';

/** Asks the main-world probe about an element. Never rejects; null on timeout or no React. */
export function probeReact(el: Element, timeoutMs = 150, win: Window = window): Promise<ReactInfo | null> {
  const nonce = Array.from(crypto.getRandomValues(new Uint8Array(8)), b => b.toString(16).padStart(2, '0')).join('');
  return new Promise(resolve => {
    const done = (v: ReactInfo | null) => {
      win.removeEventListener(PROBE_RESULT_EVENT, onResult);
      clearTimeout(timer);
      resolve(v);
    };
    const onResult = (e: Event) => {
      try {
        const d = JSON.parse((e as CustomEvent<string>).detail) as { nonce?: unknown; react?: unknown };
        if (d.nonce === nonce) done(sanitizeReactInfo(d.react));
      } catch {
        /* not ours */
      }
    };
    const timer = setTimeout(() => done(null), timeoutMs);
    win.addEventListener(PROBE_RESULT_EVENT, onResult);
    el.dispatchEvent(new CustomEvent(PROBE_EVENT, { detail: nonce, bubbles: true, composed: true }));
  });
}

/** The page can see and forge probe replies; accept only well-typed, bounded data. */
export function sanitizeReactInfo(v: unknown): ReactInfo | null {
  if (!v || typeof v !== 'object') return null;
  const o = v as Record<string, unknown>;
  const components = Array.isArray(o.components)
    ? o.components.filter((c): c is string => typeof c === 'string').slice(0, 5).map(c => c.slice(0, 80))
    : [];
  return {
    components,
    minified: o.minified === true,
    source: typeof o.source === 'string' ? o.source.slice(0, 300) : null,
  };
}

import { SCHEMA_VERSION, type PinSession } from '../shared/schema';
import type { StoreState } from './session';

export interface StorageAreaLike {
  get(key: string): Promise<Record<string, unknown>>;
  set(items: Record<string, unknown>): Promise<void>;
}

export interface PinStore {
  load(): Promise<StoreState>;
  save(state: StoreState): Promise<void>;
}

const EMPTY: StoreState = { current: null, previous: null };

export function createStore(area: StorageAreaLike, key: string): PinStore {
  return {
    async load() {
      const raw = (await area.get(key))[key];
      return isStoreState(raw) ? raw : { ...EMPTY };
    },
    async save(state) {
      await area.set({ [key]: state });
    },
  };
}

function isSession(v: unknown): v is PinSession {
  return !!v && typeof v === 'object' && (v as PinSession).version === SCHEMA_VERSION && Array.isArray((v as PinSession).pins);
}

function isStoreState(v: unknown): v is StoreState {
  if (!v || typeof v !== 'object') return false;
  const s = v as StoreState;
  return (s.current === null || isSession(s.current)) && (s.previous === null || isSession(s.previous));
}

export interface PinModeHooks {
  isOverlay(target: EventTarget | null): boolean;
  onTarget(el: Element | null): void;
  onPick(el: Element): void;
  onDismiss(): void;
  onEscape(): void;
}

const BLOCKED = ['pointerdown', 'pointerup', 'mousedown', 'mouseup', 'click', 'dblclick', 'auxclick'] as const;

export class PinMode {
  suspended = false;
  private _active = false;
  private _target: Element | null = null;
  private hovered: Element | null = null;
  private trail: Element[] = [];
  private windows: Window[] = [];

  constructor(private readonly win: Window, private readonly hooks: PinModeHooks) {}

  get active(): boolean { return this._active; }
  get target(): Element | null { return this._target; }

  enter(): void {
    if (this._active) return;
    this._active = true;
    this.windows = [this.win, ...sameOriginFrames(this.win.document)];
    for (const w of this.windows) {
      w.addEventListener('mousemove', this.onMove, true);
      w.addEventListener('keydown', this.onKey, true);
      for (const t of BLOCKED) w.addEventListener(t, this.onBlock, true);
    }
  }

  exit(): void {
    if (!this._active) return;
    for (const w of this.windows) {
      w.removeEventListener('mousemove', this.onMove, true);
      w.removeEventListener('keydown', this.onKey, true);
      for (const t of BLOCKED) w.removeEventListener(t, this.onBlock, true);
    }
    this.windows = [];
    this._active = false;
    this.suspended = false;
    this.hovered = null;
    this.trail = [];
    this.setTarget(null);
  }

  private setTarget(el: Element | null): void {
    this._target = el;
    this.hooks.onTarget(el);
  }

  private resolve(e: Event): Element | null {
    const first = e.composedPath()[0] as Node | undefined;
    if (!first || first.nodeType !== Node.ELEMENT_NODE) return null;
    const el = first as Element;
    if (this.hooks.isOverlay(el) || el === el.ownerDocument.documentElement) return null;
    return el;
  }

  private onMove = (e: Event): void => {
    if (this.suspended) return;
    const el = this.resolve(e);
    if (el === this.hovered) return;
    this.hovered = el;
    this.trail = [];
    this.setTarget(el);
  };

  private onKey = (e: KeyboardEvent): void => {
    if (this.hooks.isOverlay(e.target)) return;
    if (e.key === 'Escape') {
      e.preventDefault();
      this.hooks.onEscape();
      return;
    }
    if (this.suspended || !this._target) return;
    if (e.key === 'ArrowUp') {
      e.preventDefault();
      const parent = parentOf(this._target);
      if (parent) {
        this.trail.push(this._target);
        this.setTarget(parent);
      }
    } else if (e.key === 'ArrowDown') {
      e.preventDefault();
      const child = this.trail.pop();
      if (child) this.setTarget(child);
    }
  };

  private onBlock = (e: Event): void => {
    if (this.hooks.isOverlay(e.target)) return;
    e.preventDefault();
    e.stopImmediatePropagation();
    if (e.type !== 'click') return;
    if (this.suspended) {
      this.hooks.onDismiss();
      return;
    }
    const el = this._target ?? this.resolve(e);
    if (el) this.hooks.onPick(el);
  };
}

/** Parent across shadow and same-origin iframe boundaries; stops below <html>. */
function parentOf(el: Element): Element | null {
  const root = el.getRootNode() as Partial<ShadowRoot>;
  const p = el.parentElement ?? root.host ?? null;
  if (p && p !== el.ownerDocument.documentElement) return p;
  return el.ownerDocument.defaultView?.frameElement ?? null;
}

function sameOriginFrames(doc: Document): Window[] {
  const out: Window[] = [];
  for (const frame of Array.from(doc.querySelectorAll('iframe'))) {
    try {
      const w = frame.contentWindow;
      if (w && w.document) out.push(w, ...sameOriginFrames(w.document));
    } catch {
      /* cross-origin */
    }
  }
  return out;
}

export function h<K extends keyof HTMLElementTagNameMap>(tag: K, className?: string, text?: string): HTMLElementTagNameMap[K] {
  const el = document.createElement(tag);
  if (className) el.className = className;
  if (text !== undefined) el.textContent = text;
  return el;
}

export function button(className: string, text: string, onClick: () => void): HTMLButtonElement {
  const b = h('button', className, text);
  b.type = 'button';
  b.addEventListener('click', e => { e.stopPropagation(); onClick(); });
  return b;
}

import { OVERLAY_CSS } from './css';

export interface OverlayRoot {
  host: HTMLElement;
  shadow: ShadowRoot;
  layer: HTMLDivElement;
  isOverlay(t: EventTarget | null): boolean;
  setHidden(hidden: boolean): void;
  ensureAttached(): void;
  destroy(): void;
}

export function createOverlayRoot(doc: Document = document): OverlayRoot {
  const host = doc.createElement('pinpoint-overlay');
  host.style.cssText = 'all: initial; position: fixed; inset: 0; pointer-events: none; z-index: 2147483647;';
  const shadow = host.attachShadow({ mode: 'open' });
  const style = doc.createElement('style');
  style.textContent = OVERLAY_CSS;
  const layer = doc.createElement('div');
  layer.className = 'pp-layer';
  shadow.append(style, layer);
  doc.documentElement.append(host);
  return {
    host,
    shadow,
    layer,
    isOverlay: t => t === host || (t instanceof Node && shadow.contains(t)),
    setHidden: hidden => { host.style.visibility = hidden ? 'hidden' : 'visible'; },
    ensureAttached: () => { if (!host.isConnected) doc.documentElement.append(host); },
    destroy: () => host.remove(),
  };
}

export interface BubbleOptions {
  n: number;
  anchor: Element;
  initial: string;
  onSave(text: string): void;
  onCancel(): void;
}
export interface Bubble {
  open(o: BubbleOptions): void;
  close(): void;
  commit(): void;
  cancel(): void;
  readonly isOpen: boolean;

const WIDTH = 280;

export function createBubble(root: OverlayRoot): Bubble {
  let el: HTMLElement | null = null;
  let input: HTMLTextAreaElement | null = null;
  let opts: BubbleOptions | null = null;

  const close = () => {
    el?.remove();
    el = null;
    input = null;
    opts = null;
  };
  const commit = () => {
    if (!opts || !input) return;
    const { onSave } = opts;
    const text = input.value;
    close();
    onSave(text);
  };
  const cancel = () => {
    if (!opts) return;
    const { onCancel } = opts;
    close();
    onCancel();
  };

  return {
    get isOpen() { return el !== null; },
    open(o) {
      close();
      opts = o;
      el = h('div', 'pp-bubble');
      input = h('textarea', 'pp-bubble-input');
      input.rows = 3;
      input.placeholder = 'What should change here?';
      input.value = o.initial;
      el.append(h('div', 'pp-bubble-head', `Pin ${o.n}`), input, h('div', 'pp-bubble-hint', 'Enter to save · Shift+Enter for newline · Esc to cancel'));
      isolateKeys(el);
      input.addEventListener('keydown', e => {
        if (e.key === 'Enter' && !e.shiftKey && !e.isComposing) {
          e.preventDefault();
          commit();
        } else if (e.key === 'Escape') {
          e.preventDefault();
          cancel();
        }
      });
      const r = rectInTopViewport(o.anchor);
      const left = Math.min(Math.max(8, r.x), window.innerWidth - WIDTH - 8);
      const below = r.y + r.height + 8;
      const top = below + 120 < window.innerHeight ? below : Math.max(8, r.y - 128);
      Object.assign(el.style, { left: `${left}px`, top: `${top}px`, width: `${WIDTH}px` });
      root.layer.append(el);
      input.focus();
    },
    close,
    commit,
    cancel,
  };
}

import type { Box } from '../shared/schema';

export interface Crop { sx: number; sy: number; sw: number; sh: number; clipped: boolean; }

/** Maps a CSS-pixel viewport rect to source pixels of a captureVisibleTab image. */
export function cropRect(
  rect: Box,
  viewport: { width: number; height: number },
  image: { width: number; height: number },
  pad = 8,
): Crop | null {
  const clipped = rect.x < 0 || rect.y < 0 || rect.x + rect.width > viewport.width || rect.y + rect.height > viewport.height;
  const x0 = Math.max(0, rect.x - pad);
  const y0 = Math.max(0, rect.y - pad);
  const x1 = Math.min(viewport.width, rect.x + rect.width + pad);
  const y1 = Math.min(viewport.height, rect.y + rect.height + pad);
  if (x1 <= x0 || y1 <= y0) return null;
  const kx = image.width / viewport.width;
  const ky = image.height / viewport.height;
  const sx = Math.round(x0 * kx);
  const sy = Math.round(y0 * ky);
  return {
    sx,
    sy,
    sw: Math.max(1, Math.round(x1 * kx) - sx),
    sh: Math.max(1, Math.round(y1 * ky) - sy),
    clipped,
  };
}

import type { ScreenshotRequest, ScreenshotResult } from '../shared/messages';
import { cropRect } from './crop';

const RETRY_MS = 600;
const DOWNLOAD_TIMEOUT_MS = 10_000;

export async function takeScreenshot(windowId: number, req: ScreenshotRequest): Promise<ScreenshotResult> {
  try {
    const dataUrl = await captureWithRetry(windowId);
    const bitmap = await createImageBitmap(await (await fetch(dataUrl)).blob());
    const crop = cropRect(req.rect, req.viewport, bitmap);
    if (!crop) return { ok: false, error: 'Element is outside the viewport' };
    const canvas = new OffscreenCanvas(crop.sw, crop.sh);
    const ctx = canvas.getContext('2d');
    if (!ctx) return { ok: false, error: 'No 2D context' };
    ctx.drawImage(bitmap, crop.sx, crop.sy, crop.sw, crop.sh, 0, 0, crop.sw, crop.sh);
    const png = await canvas.convertToBlob({ type: 'image/png' });
    const path = await saveDownload(await blobToDataUrl(png), `pinpoint/${req.sessionId}/pin-${req.n}.png`);
    return { ok: true, screenshot: { path, clipped: crop.clipped } };
  } catch (err) {
    return { ok: false, error: err instanceof Error ? err.message : String(err) };
  }
}

async function captureWithRetry(windowId: number): Promise<string> {
  try {
    return await chrome.tabs.captureVisibleTab(windowId, { format: 'png' });
  } catch {
    // MAX_CAPTURE_VISIBLE_TAB_CALLS_PER_SECOND is 2; one retry after a short wait.
    await new Promise(r => setTimeout(r, RETRY_MS));
    return chrome.tabs.captureVisibleTab(windowId, { format: 'png' });
  }
}

async function blobToDataUrl(blob: Blob): Promise<string> {
  const bytes = new Uint8Array(await blob.arrayBuffer());
  let bin = '';
  for (let i = 0; i < bytes.length; i += 0x8000) bin += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  return `data:${blob.type || 'image/png'};base64,${btoa(bin)}`;
}

async function saveDownload(url: string, filename: string): Promise<string> {
  await chrome.downloads.setUiOptions({ enabled: false }).catch(() => {});
  try {
    const id = await chrome.downloads.download({ url, filename, conflictAction: 'overwrite', saveAs: false });
    await waitForComplete(id);
    const [item] = await chrome.downloads.search({ id });
    if (!item?.filename) throw new Error('Download finished without a path');
    return item.filename;
  } finally {
    await chrome.downloads.setUiOptions({ enabled: true }).catch(() => {});
  }
}

function waitForComplete(id: number): Promise<void> {
  return new Promise((resolve, reject) => {
    const cleanup = () => {
      clearTimeout(timer);
      chrome.downloads.onChanged.removeListener(listener);
    };
    const listener = (d: chrome.downloads.DownloadDelta) => {
      if (d.id !== id) return;
      if (d.state?.current === 'complete') {
        cleanup();
        resolve();
      } else if (d.state?.current === 'interrupted') {
        cleanup();
        reject(new Error(d.error?.current ?? 'Download interrupted'));
      }
    };
    const timer = setTimeout(() => { cleanup(); reject(new Error('Download timed out')); }, DOWNLOAD_TIMEOUT_MS);
    chrome.downloads.onChanged.addListener(listener);
    void chrome.downloads.search({ id }).then(([item]) => {
      if (item?.state === 'complete') { cleanup(); resolve(); }
    });
  });
}

    onFocus: n => this.elements.get(n)?.scrollIntoView({ block: 'center', behavior: 'smooth' }),
    onRestorePrevious: () => {
      this.elements.clear();
      this.state = swapPrevious(this.state);
      this.resolveElements();
      void this.commit(this.state);
    },
  });
  private readonly pinMode = new PinMode(window, {
    isOverlay: t => this.root.isOverlay(t),
    onTarget: el => (el ? this.highlighter.show(el) : this.highlighter.hide()),
    onPick: el => void this.pick(el),
    onDismiss: () => this.bubble.commit(),
    onEscape: () => (this.bubble.isOpen ? this.bubble.cancel() : this.toggle()),
  });
  private fallbackText: string | null = null;
  private screenshotWarned = false;
  private lastUrl = location.href;
  private frame = 0;

  constructor(private readonly store: PinStore) {}

  private get session(): PinSession {
    if (!this.state.current) throw new Error('Pinpoint session not initialized');
    return this.state.current;
  }

  async boot(): Promise<void> {
    this.state = sessionFor(await this.store.load(), location.href, document.title, new Date());
    this.resolveElements();
    await this.commit(this.state);
    window.addEventListener('scroll', this.onViewportChange, { passive: true, capture: true });
    window.addEventListener('resize', this.onViewportChange, { passive: true });
    let timer: ReturnType<typeof setTimeout> | undefined;
    new MutationObserver(() => {
      clearTimeout(timer);
      timer = setTimeout(() => this.onMutation(), MUTATION_DEBOUNCE_MS);
    }).observe(document.documentElement, { childList: true, subtree: true, attributes: true });
    setInterval(() => this.checkUrl(), URL_POLL_MS);
  }

  toggle(): void {
    if (this.pinMode.active) {
      if (this.bubble.isOpen) this.bubble.commit();
      this.pinMode.exit();
    } else {
      this.pinMode.enter();
    }
    this.notifyBadge();
  }

  private async pick(el: Element): Promise<void> {
    this.pinMode.suspended = true;
    this.highlighter.hide();
    const { id, nextN } = this.session;
    const element = describeElement(el);
    const [react, screenshot] = await Promise.all([probeReact(el), this.capture(el, id, nextN)]);
    const { session, pin } = addPin(this.session, {
      comment: '',
      createdAt: new Date().toISOString(),
      status: 'attached',
      element,
      react,
      screenshot,
    });
    this.elements.set(pin.n, el);
    await this.commit({ ...this.state, current: session });
    this.openBubble(pin, el);
  }

  private openBubble(pin: Pin, anchor: Element): void {
    this.bubble.open({
      n: pin.n,
      anchor,
      initial: pin.comment,
      onSave: text => {
        this.pinMode.suspended = false;
        void this.commit({ ...this.state, current: updateComment(this.session, pin.n, text) });
      },
      onCancel: () => {
        this.pinMode.suspended = false;
        this.elements.delete(pin.n);
        void this.commit({ ...this.state, current: discardNewPin(this.session, pin.n) });
      },
    });
  }

  private async capture(el: Element, sessionId: string, n: number): Promise<Screenshot | null> {
    const rect = rectInTopViewport(el);
    this.root.setHidden(true);
    await nextFrames(2);
    try {
      const res = await chrome.runtime.sendMessage<ToBackground, ScreenshotResult>({
        type: 'pp:screenshot',
        rect,
        viewport: { width: window.innerWidth, height: window.innerHeight },
        sessionId,
        n,
      });
      if (res?.ok) return res.screenshot;
      this.warnScreenshot(res?.error ?? 'no response');
      return null;
    } catch (err) {
      this.warnScreenshot(String(err));
      return null;
    } finally {
      this.root.setHidden(false);
    }
  }

  private warnScreenshot(reason: string): void {
    console.warn('[pinpoint] screenshot skipped:', reason);
    if (this.screenshotWarned) return;
    this.screenshotWarned = true;
    toast(this.root, 'Screenshot skipped');
  }

  private async copy(text: string, message: string): Promise<void> {
    try {
      await navigator.clipboard.writeText(text);
      this.fallbackText = null;
      toast(this.root, message);
    } catch {
      this.fallbackText = text;
      toast(this.root, 'Press ⌘C / Ctrl+C to copy');
    }
    this.render();
  }

  private hoverPin(n: number | null): void {
    this.markers.highlight(n);
    const el = n === null ? this.pinMode.target : this.elements.get(n) ?? null;
    if (el) this.highlighter.show(el);
    else this.highlighter.hide();
  }

  /** Re-finds pinned elements and returns true if any status changed. */
  private resolveElements(): boolean {
    const current = this.state.current;
    if (!current) return false;
    const statuses = new Map<number, Pin['status']>();
    for (const pin of current.pins) {
      let el = this.elements.get(pin.n);
      if (!el?.isConnected) {
        el = resolveSelector(pin.element.selector) ?? undefined;
        if (el) this.elements.set(pin.n, el);
        else this.elements.delete(pin.n);
      }
      statuses.set(pin.n, el ? 'attached' : 'detached');
    }
    const next = setStatuses(current, statuses);
    if (next === current) return false;
    this.state = { ...this.state, current: next };
    return true;
  }

  private onMutation(): void {
    this.root.ensureAttached();
    if (this.resolveElements()) void this.commit(this.state);
    else this.markers.reposition();
  }

  private onViewportChange = (): void => {
    if (this.frame) return;
    this.frame = requestAnimationFrame(() => {
      this.frame = 0;
      this.markers.reposition();
      if (this.pinMode.target) this.highlighter.show(this.pinMode.target);
    });
  };

  private checkUrl(): void {
    if (location.href === this.lastUrl) return;
    this.lastUrl = location.href;
    const next = sessionFor(this.state, location.href, document.title, new Date());
    if (next === this.state) return;
    if (this.bubble.isOpen) this.bubble.commit();
    this.elements.clear();
    this.state = next;
    this.resolveElements();
    void this.commit(this.state);
  }

  private async commit(state: StoreState): Promise<void> {
    this.state = state;
    this.render();
    await this.store.save(this.state);
  }

  private render(): void {
    const s = this.state.current;
    if (!s) return;
    this.markers.render(s.pins.map(p => ({ n: p.n, el: this.elements.get(p.n) ?? null })));
    this.tray.render({ pins: s.pins, previousCount: this.state.previous?.pins.length ?? 0, fallbackText: this.fallbackText });
    this.notifyBadge();
  }

  private notifyBadge(): void {
    const count = this.state.current?.pins.length ?? 0;
    void chrome.runtime.sendMessage<ToBackground>({ type: 'pp:badge', count, active: this.pinMode.active }).catch(() => {});
  }
}

function nextFrames(n: number): Promise<void> {
  return new Promise(resolve => {
    const step = (left: number) => (left === 0 ? resolve() : requestAnimationFrame(() => step(left - 1)));
    step(n);
  });
}

# Pinpoint

Pin any element on a web page, comment on it, and copy a precise reference for Claude Code (or any LLM). Pinpoint brings Claude Design's click-to-comment flow to every site.

## Install (unpacked)

```bash
mise install            # Node 22
npm install
npm run build           # → dist/
```

Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select `dist/`.

## Use

- Click the toolbar icon or press **Alt+P** to toggle pin mode (rebind at `chrome://extensions/shortcuts`).
- Hover to highlight. Press **↑** for the parent element, **↓** to go back.
- Click to pin, type a comment, then press **Enter**. **Esc** cancels.
- In the tray (bottom-right), use **Copy all** for Markdown or **Copy JSON** for the raw session. Paste it into Claude Code.

Screenshots are saved to `~/Downloads/pinpoint/<session>/pin-N.png` and referenced by absolute path, so Claude Code can open them.

After a full page reload, press Alt+P once to bring Pinpoint back; your pins are restored. Pins are kept for the browser session only.
